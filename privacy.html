Privacy Policy

Last updated: October 27, 2026

my-youtube is a personal tool operated by and for a single user (the developer). It accesses Google user data only for that user's own Google account, after that user grants consent through Google OAuth.

Data accessed

YouTube channel data (videos, playlists, comments, analytics) and Gmail messages, as permitted by the scopes the user approves.

How data is used

Data is used solely to perform actions the user requests, such as uploading videos, updating video details, and reading, organizing or sending email. Data is not used for advertising and is not sold.

Storage and sharing

OAuth tokens and any retrieved data are stored only on the user's own computer. No data is sent to any server operated by the developer, and no data is shared with third parties.

Limited Use

my-youtube's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Use of YouTube API Services is subject to the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access can be revoked at any time at https://myaccount.google.com/permissions. Deleting the local token file removes all stored credentials.
